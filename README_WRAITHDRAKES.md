# Wraithdrakes 40K Data Pack

This repo-style folder contains:
- Warhammer 40,000.gst
- Imperium - Space Marines.cat
- Imperium - Adeptus Astartes - Wraithdrakes.cat

Use all three together. The Wraithdrakes supplement catalogue follows the same pattern as official supplement catalogues such as Salamanders: it links back to Imperium - Space Marines and adds custom named units. The patched Space Marines catalogue contains the Wraithdrakes Detachment and The Grand Hunt enhancement group, because official Space Marine detachments/enhancements are stored in the core Space Marines catalogue.

Install by adding these files to a local BattleScribe/New Recruit data repository or by placing them in a GitHub repo with the rest of the wh40k-10e data files.
